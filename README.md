# 科学计算任务运营服务

这是一个面向科研平台、实验室和计算中心的 Python 后端，使用 FastAPI 与 SQLite 管理参数模板、计算任务提交、优先级排队、工作者领取、取消、失败重试、租约恢复、用户配额、结果版本和管理员人工干预记录。服务同时保留用户、角色、会话和审计等基础能力，所有运行数据都在单个本地数据库文件中，不需要另行部署数据库、缓存、消息队列或浏览器界面。

## 已有能力

- 参数模板：保存参数类型、必填项、数值范围、默认值、最大运行时间和最大尝试次数。
- 任务提交：根据模板校验参数，使用用户与幂等键避免重复创建，并保存项目、提交人和输入摘要。
- 排队领取：按优先级和进入队列的顺序分配任务，工作者可声明算法能力并获得有期限的租约。
- 执行回执：工作者可以续租、提交结果或报告失败；可重试错误使用确定的退避时间重新排队。
- 失败恢复：租约过期后可由恢复入口将任务重新排队，达到最大尝试次数的任务转为失败。
- 配额控制：可保存用户、角色或项目的排队数、运行数和每日提交上限；当前提交路径执行用户配额。
- 结果版本：每次成功回执保存不可变结果、指标摘要和内容摘要，任务指向当前结果版本。
- 结果制品：工作者完成任务时随回执提交制品清单（相对路径、大小、SHA-256 摘要、用途与临时/永久角色）；服务在本地制品目录中逐项实测大小和摘要，校验通过后与结果版本在同一事务中原子绑定。相对路径按任务命名空间隔离，拒绝绝对路径、目录穿越和符号链接；同一任务跨版本复用路径时内容必须一致。
- 发布与撤回：结果版本可发布或整体撤回，也可撤回版本内指定制品；永久制品随版本发布，临时制品不发布。重复完成回执幂等，不会制造第二份结果或制品记录；清单校验失败时任务保持运行中，不会被标成成功。
- 下载授权：只有已发布、未撤回且仍在保留期内的制品可以申请下载，申请人必须是任务提交者或管理员；授权返回带 HMAC 签名和 5 分钟有效期的下载地址。
- 清理计划：按临时、候选、已发布、已撤回四类列出制品及保留期；仍有已发布结果版本引用同一物理文件的内容会被阻止删除，计划执行只删除超期、撤回且无引用的制品文件和记录。
- 人工干预：取消、人工重试、优先级调整和批量操作均保留操作者、原因、前后状态和批次标识。
- 登录与角色：基础管理模块提供管理员初始化、用户、角色、会话和细粒度权限。

## 运行环境

- Python 3.11
- SQLite 3，由 Python 标准库提供
- Linux、macOS 或 Windows

## 安装

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -e ".[dev]"
```

默认数据库位于 `./data/compute-operations.db`。可以复制 `.env.example` 并通过 `TOWNSHIP_DATABASE_PATH` 指定其他本地路径。结果制品默认保存在 `./data/artifacts` 下按任务隔离的子目录，可通过 `TOWNSHIP_ARTIFACT_ROOT` 修改；`TOWNSHIP_ARTIFACT_RETENTION_DAYS` 控制已发布/永久制品的默认保留期，`TOWNSHIP_ARTIFACT_DOWNLOAD_SECRET` 用于下载令牌签名（未设置时使用仅适合本地验收的内置密钥）。

## 数据库初始化与检查

```bash
python -m app.cli init-db
python -m app.cli check-db
```

## 启动 API

```bash
uvicorn app.main:app --host 0.0.0.0 --port 8432
```

健康检查：

```bash
curl -sS http://127.0.0.1:8432/api/system/health
```

计算任务摘要位于 `/api/compute/summary`，模板、配额、提交、领取、回执和人工操作接口统一使用 `/api/compute` 前缀。制品相关接口包括：

- `GET /api/compute/tasks/{task_id}/artifacts`：查看任务的制品清单（可按版本过滤）。
- `POST /api/compute/tasks/{task_id}/results/{version}/publish`、`.../revoke`：发布或撤回结果版本（撤回可指定 `artifact_ids` 只撤回部分制品）。
- `POST /api/compute/artifacts/{id}/download-authorization`：校验发布状态、保留期和权限后返回带签名的临时下载地址。
- `GET /api/compute/artifacts/{id}/download?token=...`：凭签名令牌下载文件。
- `GET /api/compute/artifacts/cleanup/plan`：查看临时/候选/已发布/已撤回四类清理计划与阻止原因。
- `POST /api/compute/artifacts/cleanup/execute`：删除超期且无已发布引用的制品。

## API 冒烟

```bash
python -m app.cli smoke
python -m app.cli compute-demo
```

`smoke` 在进程内检查根路径和健康接口，`compute-demo` 会创建示例参数模板、提交一个计算任务并让匹配能力的工作者领取，用于快速确认核心运营链路。

## 目录结构

```text
app/
  compute/         计算模板、配额、任务、结果版本、结果制品和人工干预
  api/             用户、角色、认证、审计和系统管理接口
  core/            时钟、安全、异常和分页能力
  repositories/    通用 SQLite 查询
  seismic/         既有地震计算示例领域
  services/        身份、审计和通用后台任务服务
  cli.py           初始化、检查和冒烟入口
  database.py      SQLite 连接、事务、表结构与基础权限
tests/             核心、计算运营和身份回归测试
tools/             本地维护脚本
```

## 数据一致性

SQLite 连接启用外键、WAL、busy timeout 和同步写入策略。提交、领取、回执和人工干预使用即时事务；任务领取通过条件更新避免同一条排队记录被重复领取。完成回执的制品实测校验、结果版本写入、制品记录插入和任务状态翻转处于同一事务，任一步骤失败都会整体回滚；完成回执通过 `(任务, 回执号)` 唯一索引保证重试不产生重复版本。服务保存 UTC 时间字符串，测试可以注入固定时钟验证退避、租约到期、保留期和跨日配额。会话令牌只保存摘要，审计与人工干预记录不会写入明文密码或令牌。
